Proposition 3.18: The right-hand side should have a squared norm

In Theorem 3.23 on page 39, the |S| turns into a 2, and we have phi_G (G) instead of phi_G (R). The |S| should stay |S| all the way through (it's a fixed constant that factors out of the liminf); the next line correctly writes |S| again. The stray 2 was probably borrowed from the doubling bound phi_G(2R) <= 2|B(2R)| on page 38.

Also page 39, the bound Q_R(u,u) = int u^2 <= R^(2d')|B(R)| drops the polynomial-growth constant. Polynomial growth of order d' means |u(x)| <= C(1 + d(e,x))^d', so really u^2 <= C^2 R^(2d'). The constant C is what accounts for u at the origin (|u(e)| <= C); it's harmless since it only enters as a multiplicative factor in a finiteness-of-liminf statement.

More seriously, that same bound Q_R(u,u) <= R^(2d')|B(R)| is NOT correct for a general u in V: it silently drops a factor proportional to ||u||^2. Scaling u -> t*u multiplies Q_R(u,u) = int u^2 by t^2 while R^(2d')|B(R)| is unchanged, so no u-free bound can hold. The honest bound is Q_R(u,u) <= C_u^2 (1+R)^(2d') |B(R)|, where C_u = sup_x |u(x)|/(1+d(e,x))^d' is itself a norm on V, hence C_u ~ ||u|| (equivalence of norms on finite-dim V). So really Q_R(u,u) <= (const)||u||^2 (1+R)^(2d')|B(R)|.
  The line is only valid read as a bound on the Rayleigh quotient Q_R(u,u)/||u||^2 <= (const)R^(2d')|B(R)| = lambda_max(R), i.e. for normalized u. That is what makes the next line legitimate: every eigenvalue <= lambda_max, so det Q_R <= lambda_max^(dim V) and (det Q_R)^(1/dim V) <= |S|R^(2d')phi_G(R). Cleanest rigorous route: bound det via the trace (PSD => lambda_max <= trace = sum_i int u_i^2), which only involves the fixed basis functions u_i and their individual constants C_i = max, never an arbitrary linear combination. So the (det Q_R)^(1/dim V) line is correct (up to a dim-V constant); the per-u line above it is shorthand for unit u.

  Cross-checked against the sources (Kleiner, arXiv:0710.4593; Tao's blog 2010-02-18). Neither states the u-free bound Q_R(u,u) <= R^(2d')|B(R)| -- because in that form it's false. Kleiner's Thm 3.1 (= thesis Thm 3.23) takes the determinant condition liminf V(R)(det Q_R)^(1/dim V)/R^d < infty as an ABSTRACT hypothesis and just says it "clearly implies" Thm 1.4; the verification for the poly-growth space (the step Vikman spelled out, and where the bad line entered) is left to the reader in Kleiner. Where Kleiner does bound Q_R(u,u), namely Lemma 3.11 eq (3.12): Q_{R_2}(u,u) <= C V(R_1)|Phi(u)|^2 + C e^{2a} R_1^2 int_{B(2R_2)}|grad u|^2 -- both terms are homogeneous of degree 2 in u (|Phi(u)|^2 = averages of u over cover balls; int|grad u|^2 = Dirichlet energy), i.e. scale like ||u||^2, exactly as expected.
  Tao's exposition (2010-02-18) does NOT bound Q_R(u,u) uniformly either. He takes the fixed basis u_1..u_D, normalizes them to vanish at the identity (u_i(e)=0 -- a clean way to handle the origin value), and bounds the GRAM DETERMINANT directly: det(Q_R(u_i,u_j)) << R^{O(D)}, with the u-dependence (Lipschitz constants of the fixed normalized basis) absorbed into the implicit constant. That is the determinant/fixed-basis route, not a per-u bound. NOTE: the reverse Poincare inequality is NOT used to bound Q_R(u,u) -- it goes the other direction (sum|grad f|^2 << R^-2 sum|f|^2, bounding gradient energy BY L^2 mass) and belongs to the doubling/finite-dimensionality mechanism (in Kleiner, the step 3.12 -> 3.13). An earlier draft of this note wrongly cited reverse Poincare as the way the L^2 mass is bounded; that was incorrect.
  Upshot: the "correct" bound in the literature is either (a) homogeneous degree 2 in u (Kleiner 3.12, carrying |Phi(u)|^2 and the energy), or (b) a determinant bound over a fixed normalized basis (Tao). Neither is the thesis's u-free Q_R(u,u) <= R^(2d')|B(R)|; that line is a non-rigorous shorthand for Kleiner's unspelled "clearly implies" reduction.
